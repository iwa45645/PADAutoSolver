各潜入にtrialIdを付け、APK hash・コードcommit・端末・開始時刻・本体runId・開始画面・停止/クリア画面を紐付ける。B1〜B22の観測階層、操作receipt、実CD、HP、結果確認、停止理由を保存する。USBは本体の開始、インストール、証跡取得だけに使い、スキルやパズルをUSBで代行しない。

| 結果 | 扱い |
| --- | --- |
| 無中断クリア | 同じAPKで新規潜入→実CLEAR→実報酬→停止まで、修正・更新・操作の手動代行・停止後再開なし |
| 認識/探索/入力/復旧停止 | その試行の失敗として、最後の実画面と原因を記録 |
| 未対応の敵分岐 | 停止し、その試行は未対応による失敗として計上。既知分岐だけを選んで成功率を出さない |
| 敗北/誤操作 | 失敗。コンティニューや有償回復は自動選択しない |
| 通信/接続/資源不足 | 攻略ロジックの失敗と分けて記録するが、開始済み試行の集計から黙って除外しない |
| 利用者中断 | 中断として別に表示し、全開始試行の内訳を保持する |
| 修正・再開後のクリア | 開発継続の到達証拠。無中断クリアへ置き換えない |
